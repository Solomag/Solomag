### Hi, I'm Solo 👋

I make small tools that remove annoyances: ads, clutter and missing features in apps I use every day.
Mostly Android mods, Windows utilities, browser extensions and game tools — all free and open source.

**Stack:** Kotlin · C# · TypeScript · JavaScript · Xposed/LSPosed · Frida · BepInEx

---

#### 📻 Radio
| Project | What it is |
|---|---|
| [**GaGa**](https://github.com/Solomag/GaGa) | Tiny radio player for the Windows tray. One small exe, no install: https streams, FLAC, track titles, station search. |
| [**LibreRadio**](https://github.com/Solomag/LibreRadio) | Free, ad-free internet radio for Android, Android Auto, TV and Automotive. |
